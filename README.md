# 🤗 Olá, sou Yuri Deiverson!

**`Software Engineer | Python | Data & AI | FullStack`**

Sou **Software Engineer** com experiência no desenvolvimento de aplicações e APIs, atuando principalmente com **Python, Java, Spring Boot, Node.js, TypeScript e JavaScript**. Tenho experiência na construção de sistemas web, integrações entre serviços, automações e soluções orientadas a dados.

Atualmente, venho direcionando cada vez mais minha atuação para **Python, Inteligência Artificial, processamento e análise de dados**, utilizando tecnologias como **Pandas, FastAPI, Django e bibliotecas de machine learning**, sem deixar de lado minha experiência em desenvolvimento fullstack.

No desenvolvimento de aplicações, trabalho com **APIs REST, bancos de dados relacionais e não relacionais, integrações entre sistemas, autenticação, Docker e Git**, buscando construir soluções organizadas, escaláveis e de fácil manutenção.

Também possuo experiência com frontend utilizando **React, Next.js e React Native**, o que me permite atuar de forma integrada entre backend, dados e interface, compreendendo o produto de ponta a ponta.

Tenho interesse constante em **engenharia de software, dados e IA**, aplicando esses conhecimentos tanto em projetos profissionais quanto em projetos pessoais, nos quais busco experimentar novas tecnologias e transformar ideias em produtos funcionais.
